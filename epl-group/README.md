# EPL Group website

Static site, no build step. Built from the Figma file "EPL Group | Website Design"
(page "Homepage v5, editorial layers").

## Pages
index.html (home), platforms.html, team.html, track-record.html, partners.html,
insights.html, pitch.html, investors.html, careers.html, thanks.html, 404.html

## Files
css/styles.css, js/main.js, assets/ (photos, logo and monogram SVGs), favicon.svg

## Notes
- Forms are wired for Netlify Forms (data-netlify). Outside Netlify they fall back to a pre-filled email.
- Figures and transactions are placeholders from the current EPL site and are marked "to confirm before launch".
- Photos were exported from the Figma file at 1x; swap in higher-resolution originals before launch.
