# EPL Group website

Static site, nothing to build at deploy time. Built from the Figma file "EPL Group | Website Design"
(page "Homepage v5, editorial layers").

## Pages
index.html (home), about.html, faq.html, circle.html (EPL Circle), platforms.html, team.html, track-record.html, partners.html,
insights.html, events.html, pitch.html, investors.html, careers.html, 404.html

## Files
css/styles.css, js/main.js, assets/ (photos, logo and monogram SVGs), favicon.svg, favicon.ico, favicon-32x32.png, apple-touch-icon.png

## Notes
- The pages are generated by `../epl-group-build/build.py`. Edit that file, not the HTML here.
- Insights articles: one Markdown file per article in `../epl-group-build/insights/` (see the README there). Each one gets a page under `insights/` and a card on the Insights page.
- `sitemap.xml` and `robots.txt` are generated on each build.
- Google Analytics 4 (G-CBT69W3QW3) is on every page behind a cookie consent card: nothing loads from Google until the visitor accepts. The choice is stored in the browser, and "Cookie settings" in the footer reopens the card. Only eplgroup.co is counted, not previews or other domains.
- The Pitch and Investors pages embed Pipefy forms (pitch: czfdp_CJ, investor onboarding: qyeXlWs4). The Events page embeds the investor onboarding form too.
- No email addresses on the site: founders use the Pitch form, investors the Investors form, and the Careers page sends people to JOIN.
- Deploy as plain static files, for example on Cloudflare Workers static assets.
- Figures and transactions are placeholders taken from the current EPL site; confirm them before launch.
- Photos were exported from the Figma file at 1x; swap in higher-resolution originals before launch.
